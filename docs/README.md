**Need a quick answer about safety?** The five rules that never change: approval is per exact post; dry run is the default; credentials stay in your own environment; an unsure send is never repeated; `reachweaver pause` stops everything. Details are in the [security checklist](SECURITY-CHECKLIST.md).
