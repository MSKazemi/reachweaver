# ReachWeaver visual identity

The **single approved ReachWeaver icon** is [`plugin/.claude-plugin/icon.png`](../../plugin/.claude-plugin/icon.png).

It is a turquoise and gold symmetrical geometric knot, with shapes influenced by Persian geometric art, on a deep-navy rounded square. The interlacing elements stand for bringing distinct channels together while retaining a clear shared center.

## Use

- Use `plugin/.claude-plugin/icon.png` in the README, and for compact project visuals.
- The image is a 512 x 512 PNG made by upscaling the earlier 256 x 256 optimized WebP export of the final approved artwork. The earlier WebP file was removed.
- The approved original high-resolution image was 1254 x 1254; preserve a high-resolution local export before creating larger print or social assets. When it is available, replace `plugin/.claude-plugin/icon.png` with a direct export (PNG, 512 to 2048 px, under 2 MB) rather than upscaling again.
- This is **not a vector drawing**; do not describe it as SVG or as editable vector artwork.
- The README's icon is not the GitHub social-preview setting. GitHub repository social preview requires a separate upload in Settings, if desired.

The prior experimental icon, wordmark and preview are no longer included as active assets. Git history remains intact.
