# Discovery planning in Claude Code

For hashtag research, social platform discovery and post optimization, use `discovery-plan --file FILE --json`, then `seo-content-check`. Source factual claims and write a useful post for a specific audience.

The tool ranks text relevance, not platform ranking weights. Supply verified topic keywords; it may propose matching niche, broad or brand tags. Only label a tag as trending after personally observing it in a legitimate dated/region-filtered source. Record the observation date and source link. Trends expire after 14 days; unsupported or unrelated proposals are skipped.

TikTok: relevant captions and watch-through; YouTube: title, thumbnail, viewer satisfaction; LinkedIn: professional relevance; Threads: native topic label; China platforms: authentic localized content and independent eligibility checks. Read `platform-algorithms.md` for sources. Do not infer any current rank or popularity from a source homepage.

Use owner-supplied first-party metrics at matched post ages to test a hook or format hypothesis. No guaranteed views, automatic browsing, account access or publishing. See `docs/DISCOVERY-OPTIMIZATION.md` in the full repository.
