# Changelog

All notable changes to ReachWeaver are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/). `scripts/release_gate.py` requires a non-empty section for the version in `pyproject.toml`, and a `YYYY-MM-DD` date on it before a tag is created (`make release-gate TAG=vX.Y.Z`).

No section below claims a live account connection, a delivered post or a growth result.

## [Unreleased]

### Security

- **Send-state bookkeeping atomicity (owner-approved 2026-10-11 as a security-reviewed change).** `finish_send`/`uncertain_send` return a flag and write a `state_conflict` event (remote id / error code) when the post is no longer `sending`; `publish` prints `REVIEW` and logs `state_conflict` instead of `PUBLISHED`. `reconcile` is atomic and status-guarded, refuses a `sending` post claimed under 15 minutes ago unless the new `--force` is given (an existing test now passes `force=True` for a freshly claimed post). `transition` is atomic and its updates are status-guarded. `publish` retries a failed bookkeeping write briefly, then prints the remote id to stderr and counts the post as needing review without aborting the run or resending. `set_paused` and its event commit together. Tests: `tests/test_send_state_atomicity.py`.

### Fixed

- **Review hardening (offline, no safety-control change).** Campaign and policy validators no longer crash with `TypeError` on list/dict JSON values for `objective`, evidence `kind`/`verification`/`source_visibility`, variant `account_id` or `platform`; they report normal validation errors, and `main()` maps any remaining `TypeError`/`KeyError`/`AttributeError` to `ERROR: invalid input structure` (exit 2, no input echoed). `campaign-preview` renders `(missing)` for evidence without a URL. `campaign-export` validates before creating `--out`, creates it with mode 0700 and removes it if the export fails. `growth.classify_result` returns `inconclusive` when the pooled lift sign disagrees with the per-pair direction; `experiment-evaluate` now uses the same minimum-pairs / sign-test gate (no `directional_positive` for tiny samples; new `directional_negative` verdict; new `readout_label`, `readout_explanations` and `windowed_snapshots_skipped` keys, all existing keys unchanged). Snapshots with `window_start`/`window_end` are windowed counts and are excluded from matched-age comparisons in `experiment-evaluate`, `baseline-eval` and `timing-analysis`, with a warning/count. Engagement matching collapses all whitespace so newline-split injection directives are flagged `suspicious`. `Content-Length`/analytics counts accept ASCII digits only (`"²"` is a validation error, not a crash). Postiz `_call` converts `http.client.HTTPException`, `InvalidURL` and `ValueError` into fixed `PublishError` codes without echoing headers. LinkedIn drafts whose escaped commentary exceeds 3,000 characters are refused by `validate_post` (a heavy use of `*` or `_` could previously pass the raw 2,800 cap and be rejected by LinkedIn after the send claim). Tests: `tests/test_review_hardening.py`.

### Fixed

- **`ops-metrics --out` could overwrite the state database (issue #26, review F1).** `--out` atomically replaced any path, so `--out state/reachweaver.sqlite` replaced the database with metrics text, set it to mode 0644 and printed `database unchanged`. `ops_metrics.write_textfile` now refuses, with exit 2 and nothing written, the database itself (same path, same resolved path or a hard link, via `os.path.samefile`), any symbolic link, a directory, and an existing file whose name does not end in `.prom` or `.json`; a new file may have any name. On a database from an older version, `ops-metrics` names the missing columns (new `storage.schema_gaps`) and exits 2 without migrating, and `engagement-fetch` reads it unchanged (it needs only the original `posts` columns). `metrics-fetch` writes snapshots and still uses `connect`. - **`engagement-fetch` cut reply text before redacting it (issue #17, review F1).** An e-mail address, token or phone number crossing the 4000-character cap was seen only partially by the redaction patterns, so a fragment such as `john.doe@examp` or the first 4000 characters of a JWT reached the export. - **One Bluesky reply with an empty handle made the whole `engagement-fetch` export fail (issue #17, review F1).** `write_export` rejected the document (`author_handle must be a non-empty string`). An empty or missing handle now falls back to the author's DID; a reply with neither is skipped and noted as `reply_without_author_identity_skipped`.
- **A credential with a control character could leak into `ERROR:` output (issue #5, review F1).** A `$CREDENTIALS_DIRECTORY` file ending in `\r\n` kept its `\r`, `http.client` refused the header with `ValueError("Invalid header value b'Bearer <token>\\r'")`, and the CLI printed that message, token included. `accounts.credential` now strips exactly one trailing `\n` or `\r\n` from a file and refuses any value, from a file or the environment, that still contains a C0 control character or DEL (`credential NAME contains control characters`, name only). ### Fixed

- `media-check` subtitle URL warnings show only scheme, host and path (`?…` marks a hidden query or fragment); a translated cue's `?token=` query string or `user:password@` no longer reaches the report.
- **Release gate: human-only rows can no longer drop their `distribution_id`.** The human-only ⇒ `blocked` rule ran only when a scorecard row had `distribution_id`, so deleting it from the `hacker_news` row let that row claim `offline_mock_tested`. A row whose `id` or `capability_id` names a human-only distribution-registry entry must now carry that entry as `distribution_id` and be `blocked` (`scripts/release_gate.py`; `ReleaseReadinessScorecard` in `tests/test_onboarding.py`).
- **`media-check` translated subtitles.** A URL that a translated cue adds and its source cue lacks is now a warning (a link injected during translation is a phishing risk). Digit runs are normalised as text instead of `str(int(run))`, which raised `ValueError` past Python's 4300-digit limit; leading zeros are ignored and long runs are shortened in findings. An SRT index such as `²` or `①` (accepted by `str.isdigit()`, rejected by `int()`) crashed the check and is now a "numeric index" error, and an over-long timestamp hour field is a malformed timestamp instead of an `int()`/`float()` overflow. Locale tags compare case-insensitively (RFC 5646), so an `en-us` track is the source of an `en-US` asset and `target_locales` matching ignores case. See [docs/MEDIA-ASSETS.md](docs/MEDIA-ASSETS.md#translated-subtitle-tracks).
- **`calendar-plan --audience-activity` DST fall-back collision.** When a fall-back in the planner zone mapped two activity hours to the same local slot (UTC CSV, `as_of` 2026-10-21, Europe/Rome: Sunday 00:00 and 01:00 UTC are both 02:00), the lower-ranked hour's provenance overwrote the top hour's and one top hour was lost. `audience.derive_slots` now keeps the higher-ranked hour, warns with the dropped hour, and fills from the next-ranked hour; `calendar.propose_calendar` also keeps the first provenance per window. See [docs/CALENDAR-PLANNER.md](docs/CALENDAR-PLANNER.md).
- **Similarity tokenizer and zero-width spaces in Thai, Lao, Khmer and Myanmar.** Dropping every format character also removed U+200B where these scripts use it as the word break, so a one-word edit in ZWSP-segmented Thai scored 0.00 instead of 0.40. U+200B next to a letter of those scripts is now a space; elsewhere it, the joiners, word joiner, BOM, soft hyphen and bidi controls are still dropped, so the zero-width evasion tests stay green. See [docs/CLAIM-GROUNDING.md](docs/CLAIM-GROUNDING.md#posting-history).
- **Markdown table escaping.** `media-storyboard` put the owner's `--safe-zones` source URL (and campaign ids) into its Markdown tables raw, so a `|`, backtick or newline could add cells or rows; these cells are now escaped. `report --format markdown` cells now also escape backslash, backtick, `[ ] ( ) * _` (CommonMark backslash escapes) besides pipes and HTML, as defence in depth (`report_format.markdown_cell`).
- `media-check` now rejects SRT or WebVTT subtitle files that still contain an unresolved placeholder or TODO.
- `reachweaver.__version__` said `0.1.0` while `pyproject.toml` said `0.2.0`. Both now say `0.2.0`, and the release gate fails on any mismatch.
- The README five-minute setup scheduled a post for a future time and then ran `publish --post-id`, which refuses posts that are not yet due. The preview now runs before `schedule`.
