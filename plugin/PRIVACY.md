# ReachWeaver plugin privacy notice

See the canonical, public [ReachWeaver privacy notice](../PRIVACY.md), including local storage, opt-out, update checking, external platforms, deletion limitations and contact information.

The installed plugin runs a session-start GitHub update notice; live publishing requires operator action and safeguards. Local content **is retained** in the operator's own SQLite database until the operator explicitly manages or purges it, subject to preserved safety metadata.

For plugin listing purposes: https://github.com/MSKazemi/reachweaver/blob/main/PRIVACY.md
